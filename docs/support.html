Common Troubleshooting Guides

Quick resolutions for the most frequent questions.

There are three common reasons:

  1. Highlighting user prompts instead of AI responses: By design, Quote Reply only anchors onto Gemini's output turns (model-response) to prevent accidental triggers while you type your own prompts.
  2. Google Native Coexistence: In v2.8.2+, if Google has activated their native experimental quote feature on your account, the extension yields to avoid showing duplicate buttons.
  3. Quote Reply disabled in popup: Click the extension icon in your toolbar and verify the "Quote Reply" toggle is turned on.

Open the Bookmarks drawer in Gemini by clicking the bookmark icon in the sidebar (or press Ctrl+Shift+B). In the top right corner of the Bookmarks panel, click the Export button. You can export as:

  • Markdown (.md): Formatted with turn titles, timestamps, and response markdown for import into Obsidian, Notion, or Roam.
  • JSON (.json): Complete raw backup that can be imported on any other computer running the extension.

By default, whenever you paste text longer than 5,000 characters, Smart Paste intercepts it to prevent the Gemini text composer from freezing. It creates a virtual pasted_text.txt attachment. You can configure whether it asks confirmation or executes automatically in the extension popup settings.

Google frequently updates Gemini's Angular component class names and DOM structures. Instead of waiting 3–7 days for Chrome Web Store update reviews every time a selector changes, our extension loads fallback selectors from our GitHub repository in real time with local caching. It heals silently.
